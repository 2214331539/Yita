译獭 · Yita 快速开始
===================

运行
1. 源码用户先安装 .NET 8 SDK，在项目目录执行 scripts\Build-Local.ps1，再双击 Start-Yita.cmd。
2. 本地构建位于 artifacts\Yita-ui，运行需要 .NET 8 Desktop Runtime。
3. 若使用自行生成的 Windows x64 自包含 ZIP，解压全部文件后启动 Yita.exe，无需另装 .NET。
4. 先退出其他 Yita 或旧版翻译程序，避免划词与快捷键冲突。

首次配置
- 在设置中填写 API Key、服务地址与有效模型名称，测试连接后保存。
- 默认服务为 https://api.deepseek.com；API 调用费用由所用服务计费。
- 右上角可切换中文 / English。API Key 保存在 Windows 凭据管理器。

阅读
- 鼠标拖选可读取的文本后，译文以流式形式出现在选区附近。
- 顶部“原文 / 译文”切换显示内容，图钉固定窗口，× 关闭当前窗口。
- 拖动顶部短横条移动窗口；拖动边缘调整大小。
- 点击正文后选中文字，按 Ctrl+C 或使用右键菜单复制。
- 默认字号在设置中调整；浮窗内可使用 Ctrl+加号 / 减号。
- 底部可继续提问；其他原工具栏入口已隐藏。
- 默认主题为“译獭 · 湖畔”：奶油白阅读面、深暖灰正文与湖水绿按钮。

无法自动取词时
- 先自己按 Ctrl+C，再按 Ctrl+Shift+T；或从托盘选择“翻译剪贴板”。
- 该快捷键不替你模拟复制。
- “兼容性剪贴板回退”默认关闭，开启后自动取词可能临时改变系统剪贴板。
- 如遇复制冲突，先暂停划词、关闭兼容回退并回到原窗口复制。

数据与限制
- 当前只支持 Windows；不含 OCR、Setup 安装器或自动更新。
- 扫描 PDF 无法直接取词，Zotero 内置 PDF 兼容性尚未解决。
- 选中文字会发送到配置的在线服务；启用上下文后可能同时发送所在段落。
- 普通缓存只保存在内存；手动修正进入本地加密记忆。
- AI 自动记录默认关闭；主动保存的 Markdown 记录为明文，请妥善保存。
- 设置位于 %LOCALAPPDATA%\Yita\settings.json。
- 托盘菜单可暂停、设置或完全退出；关闭设置页不会退出程序。
- 分发时保留 LICENSE、NOTICE.md 和字体许可。
