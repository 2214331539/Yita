## 本版内容

- Core 共享 DeepSeek 流式翻译、请求取消、缓存、设置、解释/问答和记录机制。
- Avalonia 还原 Yita 设置页、阅读浮窗、主题、字体、语言同步、缩放和相对选区拖动位置。
- Windows 保留独立 UIA 进程、原生控件取词、Ctrl+C 回退、全局快捷键、托盘与开机启动；安装包同时携带主程序和隔离 helper 各自的运行时。
- Mac 已接入 Swift Accessibility/AX 取词、显式 Cmd+C 回退、权限管理、鼠标与快捷键、菜单栏、Keychain、登录项及睡眠恢复代码。
- 两端自包含安装包、完整许可、封装后启动检查及一致的发布版本；两端构建/测试成功后才一起发布。

## 首次使用

Windows 退出其他 Yita 后运行 Setup，从 `Yita Preview` 快捷方式启动。新版与旧 WPF 版使用不同安装标识，不自动删除旧版；请只运行一份取词应用。

Mac 打开 DMG，将 `Yita.app` 拖入“应用程序”。本包为 ad-hoc 签名，尚未经过 Developer ID 签名及 Apple 公证，首次启动可能需在“系统设置 → 隐私与安全性”中允许打开。然后在 Yita 设置页申请并检查辅助功能、输入监控权限。

两端都需填写自己的 DeepSeek API Key，测试连接并保存。在线 API 的调用费用由所选服务计费。详细步骤见随包 `WINDOWS_TESTING.md` / `TESTING.md`。

## 验证与限制

这是公开预览版。自动化、运行时/helper 启动、Windows 安装/重装/卸载及 Mac DMG/ZIP 封装检查会在发布流水线中执行；Mac 外部应用划词、真实授权、Keychain、Retina/多屏和桌面生命周期仍待真机反馈。Windows 更多朋友电脑上的 Avalonia 安装与应用兼容性也需继续复验。

Windows 安装包尚未做商业 Authenticode 签名；Mac 未公证。没有 OCR，不支持扫描图、密码框、禁止复制或不提供选区/安全复制接口的内容，不承诺所有软件都能自动取词。

当前没有应用内自动更新。新版本由 GitHub Release 提供，退出后重新运行 Setup 或替换 Mac 应用/完整 ZIP。卸载默认保留用户数据。此预览仍使用 .NET 8；LTS 升级、正式签名公证和稳定版验收继续按开发路线推进。

历史 `v0.8.4` WPF Release 及原源码分支保持不变，本版不会重写旧标签或覆盖旧安装包。
