## 更新内容

- 修正 Mac 自动划词的窗口过滤：后台被遮挡的 Yita 窗口不再仅因坐标重叠而阻止外部取词，原生 helper 按真实窗口层级识别。
- 改进辅助功能和输入监控权限提示；保存原生取词配置后保持设置页可见，授权后可重新检查和修复输入捕获。
- 增加从 DMG 或应用转移临时目录运行时的安装提示，并阻止从这些临时位置注册登录启动。
- 增加不记录选中文字或 API Key 的取词诊断计数，便于排查无响应。
- Windows 同步包含最新共享界面与宿主修复；两端使用同一版本，下载文件名统一为 Yita。

## 安装与更新

**Windows**：退出正在运行的 Yita，运行 `Yita-Setup.exe`。新版 Avalonia 使用独立安装身份；请避免与旧 WPF 版同时运行。

**Mac**：打开 `Yita.dmg`，将 `Yita.app` 拖到“应用程序”，弹出磁盘映像，再从“应用程序”启动。打开 DMG 中的应用不会自动完成安装。更新时先退出旧应用，再替换完整 `Yita.app`。

Mac 包使用 ad-hoc 签名，尚未完成 Developer ID 签名和 Apple 公证；首次打开可能需要在“系统设置 → 隐私与安全性”中允许。请为安装后的 Yita 授予“辅助功能”和“输入监控”权限，再回到 Yita 检查权限或修复输入捕获。升级后若系统仍保留旧授权，可移除旧 Yita 权限条目并重新添加“应用程序”中的新版。

填写自己的 DeepSeek API Key，测试连接并保存。开启划词翻译后，在普通网页拖选可复制文字；Mac 也可先 `Cmd+C`，再 `Cmd+Shift+T` 翻译剪贴板。

## 验证与限制

发布流程在 Windows/macOS 上执行共享及原生适配测试、运行时/helper 启动检查、Windows 安装/重装/卸载和 Mac DMG/ZIP 封装检查，两端全部成功后才发布。包版本、源码提交与内部文件哈希会在上传前核验。

这是公开预览版，Mac 真实权限和各软件划词效果仍需真机验收。Windows 包尚未做商业 Authenticode 签名，Mac 未公证；无 OCR，不支持扫描图片、密码框、禁止复制或不提供选区接口的内容。当前没有应用内自动更新，安装新版不会自动修改正在运行的进程。

更多试用步骤：[Windows](https://github.com/2214331539/Yita/blob/v0.9.0-preview.2/docs/WINDOWS_PREVIEW_TESTING.md) · [Mac](https://github.com/2214331539/Yita/blob/v0.9.0-preview.2/docs/MAC_PREVIEW_TESTING.md)。
