本版将最新跨平台实现合入 `main`，Windows 和 M 系列 Mac 均从同一标签、同一干净源码构建，包含浮窗目标语言快捷切换和此前 Mac 安装、权限与划词修复。

## 下载与安装

| 系统 | 唯一需要下载的安装包 | 安装方法 |
| --- | --- | --- |
| Windows 10 1809+ / Windows 11 x64 | [Yita-Setup.exe](https://github.com/2214331539/Yita/releases/download/v0.9.0-preview.3/Yita-Setup.exe) | 退出旧 Yita，运行安装向导 |
| Apple Silicon Mac，包元数据最低 macOS 12.0 | [Yita.dmg](https://github.com/2214331539/Yita/releases/download/v0.9.0-preview.3/Yita.dmg) | 打开 DMG，将 `Yita.app` 拖入“应用程序”，弹出镜像后启动 |

安装包自带运行时，无需预装 .NET、SDK 或 Xcode。Mac 仅支持 M 系列芯片。上传附件只有这两个安装包；ZIP、SHA256、构建清单与测试记录仅用于内部验证。GitHub 自动生成的 Source code 归档无需下载。

## 新增功能

- 阅读浮窗在“原文 / 译文”左侧增加目标语言下拉框，提供与设置页一致的自动判断、简体中文、英语和日语。
- 切换后立即用当前原文重新翻译，并保存为默认目标语言，后续划词与重启继续沿用。中英文混合句子可直接选英语，无需打开设置页。
- 旧请求会被取消，迟到结果不能覆盖新译文；保留当前固定状态、选区锚点和手动调整的窗口尺寸，其他固定窗口保持各自内容。
- 下拉菜单沿用 Yita 配色、圆角与字体，支持中英文界面。设置页仅同步语言字段，不提交其他未保存配置；保存失败显示提示，只读配置保持保护。

## 同步包含的改进

- Mac 按真实窗口层级过滤自身窗口，避免被遮挡的 Yita 窗口误拦截其他应用的选区。
- 辅助功能与输入监控权限提示、授权后检查和输入捕获修复，以及 DMG/临时运行目录的安装引导。
- Windows UIA 隔离、Ctrl+C 回退、DeepSeek 流式翻译、解释/问答、缓存和记录机制。

## 首次使用与更新

请先退出旧版，避免同时运行多个取词程序。Windows 使用当前 Avalonia 安装器，旧 WPF 安装身份不同，需要自行退出旧应用。Mac 请从“应用程序”运行已安装的 Yita，打开 DMG 不等于安装。

Mac 尚未完成 Developer ID 签名与 Apple 公证，首次运行可能需要在“系统设置 → 隐私与安全性”中允许打开，并为 Yita 或其原生 helper 授予“辅助功能”“输入监控”权限。升级后如授权仍指向旧应用，请移除旧条目并重新添加已安装的新版，再检查权限或修复输入捕获。

配置自己的 DeepSeek API Key、测试连接并保存。自动划词失败时可先复制，再使用 Windows `Ctrl+Shift+T` / Mac `Cmd+Shift+T`，或菜单“翻译剪贴板”。当前没有应用内自动更新，升级需重新运行 Setup 或替换完整 `Yita.app`。
