本版将 `mac` 分支的取词兼容修复打包发布。Windows x64 与 M 系列 Mac 均为当前 Avalonia 应用，从同一标签、同一干净源码构建。Mac 内部构建号为 **5**。

## 下载与安装

| 系统 | 安装包 | 安装方式 |
| --- | --- | --- |
| Windows 10 1809+ / Windows 11 x64 | [Yita-Setup.exe](https://github.com/2214331539/Yita/releases/download/v0.9.0-preview.4/Yita-Setup.exe) | 退出旧 Yita，运行安装向导 |
| Apple Silicon Mac，包元数据最低 macOS 12.0 | [Yita.dmg](https://github.com/2214331539/Yita/releases/download/v0.9.0-preview.4/Yita.dmg) | 将 `Yita.app` 拖入“应用程序”，弹出 DMG 后启动 |

只需下载对应系统的一个安装包。两个安装包均自带 .NET 运行时，无需安装 SDK 或 Xcode。上传附件仅有这两个安装包；GitHub 自动生成的 Source code 归档不用于安装。

## 本版改动

- Mac 自动取词的 Cmd+C 回退同时检查焦点元素、鼠标松开处的元素及其祖先，并扩展文档容器角色支持，改善编辑器、PDF 阅读器和办公软件中焦点为容器时被拒绝取词的问题。仍保留受保护控件、前台来源、权限、取消和剪贴板恢复检查。
- 已取得选中文字时，可选 AX 范围、坐标和上下文查询失败不再丢弃正文；没有选区坐标时使用本次拖选区域或鼠标定位。
- 性能诊断补充实际划词开关、鼠标按下/松开/取消计数及最近一次取词错误码。点击菜单栏“复制性能诊断”后，稍等并按 `Cmd+V` 粘贴查看。
- 保留浮窗目标语言快捷切换、默认目标语言保存、DeepSeek 流式翻译及现有 Windows 取词功能。

## 更新说明

请先退出旧版。Windows 重新运行 Setup；Mac 替换“应用程序”中的完整 `Yita.app`，不要直接长期运行 DMG 内的应用。更新后检查“辅助功能”和“输入监控”，必要时重新添加已安装应用或其原生 helper。

本版仍为公开预览。容器取词范围扩大后，非文字区域的误触发与不同软件的兼容性仍需真机验收。自动划词失败时，可手动复制后使用菜单“翻译剪贴板”，或 Windows `Ctrl+Shift+T` / Mac `Cmd+Shift+T`。

Mac 仍使用 ad-hoc 签名，尚无 Developer ID 签名及 Apple 公证，首次启动可能需要在“系统设置 → 隐私与安全性”允许打开；本次取词修复不消除该系统提示。Windows 安装包尚无商业代码签名。

## 发布验证

发布流水线在 Windows/macOS 构建并运行共享、原生适配和界面测试，检查 Windows 安装/重装/卸载，以及 Mac 原生策略、helper、自带运行时、ARM64 二进制、签名和 DMG 封装。两个平台通过后，核验源码、版本与 SHA256，上传且重新下载校验这两个安装包。

这些检查不替代真实桌面权限、外部应用和多屏环境验收。本版不含 OCR，不保证读取扫描图片、密码框、禁止复制或不提供选区的控件。
