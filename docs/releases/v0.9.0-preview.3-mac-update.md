## Mac 安装包更新（2026-10-10）

本次仅替换 Apple Silicon 的 `Yita.dmg`，内部构建号为 **4**。Windows 的 `Yita-Setup.exe` 保持原发布文件。Release 标签仍指向最初的发布提交；更新后的 Mac 安装包来自单独的修复提交，具体打包源码见下方记录。

- 修复已经取得选中文字，却因可选 AX 范围、选区坐标或上下文查询失败而丢弃正文、无法显示浮窗的问题。没有坐标时使用本次拖选区域或鼠标定位。
- 补充自动划词实际启用状态、鼠标按下/松开/取消计数，以及最近一次取词错误码，帮助区分权限、鼠标监听和选区读取故障。诊断不包含选中文字、来源应用或 API Key。
- 点击“复制性能诊断”后，在聊天或“文本编辑”中按 `Cmd+V` 粘贴；此操作不会打开诊断窗口。

Windows/macOS 各通过 507 项测试；Mac 原生策略和打包后的主应用/helper、自带运行时、ARM64 架构、签名及 DMG 挂载检查通过。这些检查不替代 Mac 真机授权与外部应用验收。

更新时请从菜单栏退出旧 Yita，将新 DMG 内的 `Yita.app` 拖入“应用程序”替换旧版，弹出 DMG 后启动，再检查“辅助功能”和“输入监控”权限。此包仍使用 ad-hoc 签名，尚未完成 Developer ID 签名或 Apple 公证。
