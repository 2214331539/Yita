# Windows Avalonia 原版还原计划

> 历史文档：还原及后续修复已进入 `main`，原本地 `codex/windows-avalonia-parity` 分支已删除，提交历史仍保留。本文的基准和约束描述当时的还原阶段；当前状态见 [Windows 验收记录](WINDOWS_AVALONIA_ACCEPTANCE.md)，下一步以 [跨平台产品开发路线图](CROSS_PLATFORM_ROADMAP.md) 为准。

## 分支与基准

- 开发分支：`codex/windows-avalonia-parity`，从 `ae024e3` 的跨平台预览创建。
- 用户选择：Windows 继续使用 Avalonia，按原版逐页还原；不使用 WPF 替代新界面。
- 原版参考：当前检出中的 `src/Yita.App`，该目录、`tests/Yita.Tests`、`Yita.sln` 和正式安装发布脚本保持不变。
- 本地 main 基准：`a6a5c32086d0c24e1e322f57a46e75b89ea26833`。
- 远程 main 基准：`4ad91b758e55f4ca5abe86d96dd62a1d157708c1`。
- `v0.8.4` 标签基准：`5082d8571d3eed9db0cc0c6666f73db5eaa8673d`。

## 实施顺序

1. 复用原版平台无关业务代码，包括完整 DeepSeek 翻译/解释/问答/总结、重试与熔断、LRU 缓存、术语表、语言方向、记录与设置规则。采用编译链接，不修改原文件；原版测试另行编译到 Core 测试工程验证。
2. 按原版设置窗口的 980 × 760 基准还原头部、178px 导航、卡片、字段、切换语言、字体、主题、浮窗样式预览和底部操作。页面包括常规、AI 记录、翻译与外观、模型配置。
3. 按原版浮窗还原外置阅读控制、拖动把手、正文、加载/错误、原文/译文、固定/关闭、解释、修正、问答与快速聊天；支持键盘交互、尺寸与相对定位。
4. 恢复 Windows 原版触发语义与可靠性：Ctrl+Shift+T 翻译用户已复制的剪贴板，鼠标取词使用独立 UIA Worker、原生控件和受控复制回退，WPS 独立开关、钩子恢复、隐私诊断和正常复制。
5. 保持预览数据隔离，接入原版记录目录、手动记录、总结和 Windows 加密翻译记忆；既有预览设置可迁移，正式版数据只作为读取参考。
6. 比对原版和 Avalonia 各页面截图，并验证普通/高 DPI、长文、玻璃样式、固定多窗口、请求并发、托盘、退出和重启。

## 验收约束

- 原版源码、main、正式标签和正式 Setup 入口不发生修改；本分支不发布正式版本。
- 新界面使用 Avalonia；禁止通过启动旧程序冒充迁移完成。
- 复用原版业务机制并保留独立回归测试，不能以简化逻辑替代未迁移功能。
- 控件位置、尺寸、字重、间距、主题资源、交互状态与动效以原版代码和截图为依据。
- 只有完成截图比对和功能验收的页面才能标记为还原完成；跨框架字体栅格化差异须如实记录。
- macOS 原生实现与验收不属于本轮，跨平台业务层必须保持 net8.0 可构建。

## 已完成的关键修复

- Windows `INPUT` 联合体补齐原生鼠标成员，修复 x64 结构从 32 字节变为 Win32 要求的 40 字节；模拟复制实测通过。
- 复制已发送后继续观察并还原剪贴板，再处理取消；按剪贴板序列和所属窗口避免覆盖后续用户复制。
- 阅读内容和问答角色标题按原版字体、字号、间距与颜色渲染；问答保留跨段落文本选择。
- 手动解释和问答记录增加保存状态及重复保存保护；旧解释的保存结果不能覆盖新解释。
- 完成解释后的追问使用 `Explanation` 上下文；快速聊天使用 `GeneralChat` 上下文。
- 切换语言后同步更新 Avalonia 下拉框选中项的可见文字；导航项悬停保持选中颜色，英文标签允许换行。
- 点击反馈、开关移动、页面与浮窗揭示动画使用原版时长和缓动，遵循 Windows 动画与高对比度偏好。
- 后台运行时重复启动通过命名事件打开已有设置窗口，保留单实例钩子所有权。
- 语言切换同步到托盘、翻译浮窗与问答窗口，包括已打开窗口和加载状态；取消恢复已保存语言。
- 托盘菜单按内容预先测量，使用点击屏幕的 DPI 与工作区定位，覆盖不同缩放与负坐标屏幕的回归检查。
- 通用 Ctrl+C 回退默认开启并迁移旧预览默认值；保留后续显式关闭。补齐 WPS 嵌入进程、焦点子进程剪贴板归属与选区稳定等待，保护密码控件与终端。
- OLE 剪贴板分阶段写入时等待稳定；同一目标的延迟格式渲染不误判为其他用户复制，复制及取消恢复的原生实测重新通过。
