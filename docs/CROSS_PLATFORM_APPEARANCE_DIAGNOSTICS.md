# 跨平台字体、动效与取词诊断

更新日期：2026-10-02。实现位于 `codex/platform-host-services`，本批不创建安装包或 Release，也不将 Mac CI 作为真实桌面验收。

## 字体与图标

Windows 保留当前微软雅黑界面与原版译文字体选项。macOS 界面优先使用已安装的 PingFang SC、Heiti SC 或 Helvetica Neue；没有任何候选时使用 Avalonia 默认字体。

译文字体先保留已安装的用户选择，再按字体类别回退：

| 保存的偏好 | macOS 缺失字体时的优先回退 |
| --- | --- |
| Microsoft YaHei/UI、SimHei | PingFang SC、Heiti SC |
| SimSun | Songti SC、STSong、PingFang SC |
| KaiTi | Kaiti SC、STKaiti、PingFang SC |
| Times New Roman、Cambria | Times、Georgia、Helvetica Neue |
| 其他未安装的西文字体 | Helvetica Neue、Helvetica、Arial、PingFang SC |
| Source Sans Pro | 已附许可的项目内置字体 |

设置文件仍保存现有选项 ID，避免同步或导入 Windows 阅读偏好后被永久改写。Mac 下拉框显示实际解析的字体名称，因此多个旧选项可能映射到同一字体。中英文译文、解释和问答正文按文字脚本拆分字形；问答角色保持粗体与既有段间距。菜单、设置和对话框使用同一平台界面字体；非 Windows 的固定、关闭及勾选标记使用现有矢量图标，避免依赖 Segoe 私有字形。没有附带 Windows 系统字体。

## 动效偏好

“翻译与外观”增加“减少动效”开关。切换立即预览到已打开与后续窗口，取消恢复已保存设置，保存后重启仍生效。`reduceMotion` 是 schema 1 的新增可选字段，旧文件缺失时默认为 false。

有效动效条件为应用允许动效、未启用减少动效且系统允许动效。Windows 使用现有动画/高对比度偏好；Mac 在实际 Cocoa 主线程读取 `NSWorkspace.accessibilityDisplayShouldReduceMotion`。启动时读取，之后 UI 定时器每 2 秒检查，仅在值变化时刷新动效资源。Headless 测试不读取 Cocoa 偏好。

减少动效时，窗口/页面揭示、按钮缩放和开关过渡停用；正在揭示的控件取消动画并恢复原透明度、变换及变换原点。连续揭示、控件分离和异步动画失败均有收尾，不让旧动画把新窗口留在透明状态。测试可注入系统偏好；CI 的独立 Mac probe 只读取实际偏好并检查线程约束，不修改系统设置。

## 取词失败反馈

`SelectionIssueClassifier` 只将已知原生代码映射到固定枚举；其他内容按结构化失败类型归类，不显示原始诊断字符串。识别组件缺失/版本不匹配、重启限频、权限拒绝、超时、保护内容、不安全复制、剪贴板变更、字符超限和不支持的应用。

- 自动划词失败不会弹出失败窗口或调用模型。常规页显示最近一次有操作建议的错误；普通空选区和取消不覆盖该错误，下次成功读取后隐藏。
- 手动翻译失败显示中英文对应原因；切换界面语言会同步已有错误浮窗。一般取消不弹窗，剪贴板冲突和字符超限仍保留实际错误信息。
- 复制受保护内容或读取不到字并不代表网络、防火墙或 API Key 错误；模型请求失败继续使用独立的翻译错误处理。

## 诊断边界与计时

托盘“复制性能诊断”附带本次运行的完成读取计数、固定错误类型及最近 128 条样本中的成功取词 p50/p95，按 Accessibility、ClipboardFallback 和 ManualClipboard 分组。计时从原生/剪贴板读取调用开始，到结果返回结束；包括读取过程的排队、重试和恢复，不包括用户设置的触发等待、界面调度和模型网络时间。

诊断容器只保留触发枚举、结果枚举、成功读取来源和有效耗时，不保留选区/译文、上下文、来源软件、PID、指针/选区坐标、路径、API Key 或原始错误字符串。最近样本有上限，退出后清空，不写持久化记录。现有健康日志仍记录宿主进程信息，但不记录来源应用及正文。

计数只涵盖已完成且交付到 Desktop 的读取；被新输入替换的中途操作不计入。空选区可能来自普通非文本拖动，所以报告不宣称这是有效选区成功率，不能用它替代每个应用 100 次有效拖选的兼容性矩阵。

仍需手动验收：

1. Windows 开关预览、取消、保存及重启；改变系统动画设置后无需重启即可跟随，固定窗口与托盘命令继续工作。
2. 中英文混排、长段落、字号上下限及复制；Mac 需检查实际字体、菜单符号、换行和 Retina 测量。
3. 真实目标拒绝/不支持、剪贴板占用或冲突、权限撤销与 helper 故障时，反馈对应实际原因且普通复制保持可用。
4. Mac 实际授权、外部划词、Cmd+C、Keychain、Spaces/全屏、多屏和签名验收继续暂缓。独立 Cocoa probe 不能替代这些条件。
