# 译獭 · Yita — 品牌素材 v1

角色昵称：獭獭。一只抱着湖水绿小词典的圆脸水獭，定位为安静、友好的英文阅读搭子。词典上的对话气泡表达语言沟通。

## 文件用途

- `yita-mascot.png`：全身角色，透明背景，可用于欢迎页、关于页面、空状态和产品介绍。
- `yita-app-icon-master.png`：圆角方形 Logo 原图，透明外围。
- `yita-icon-{尺寸}.png`：16、20、24、32、40、48、64、128、256、512、1024 像素 PNG。
- `yita.ico`：Windows 多尺寸图标，包含 16–256 像素的多个条目。
- `export-icons.ps1`：从原图重新导出尺寸与 ICO 的脚本。
- `generation-prompts.md`：生成及调整时的完整提示词。

## 设计约定

- 名称：译獭 · Yita。
- 特征：低位圆耳、奶油色双瓣嘴边、深棕色鼻子和微笑、短胡须、词典。
- 建议界面配色：暖棕 #A56F4C、奶油白 #FFF0D8、深棕 #442F28、湖水绿 #2D8C83。生成图有轻微色调变化，色值作为后续 UI 设计参考。
- 图标中不放品牌文字，避免缩小后难以阅读；界面可单独使用真实字体显示“译獭 · Yita”。
- 16–24 像素下以轮廓和色块为主，正式托盘接入时需在深浅任务栏与不同缩放下检查；可进一步设计专用单色标志。
- 这些是 PNG 位图与 ICO 导出文件，不是 SVG 矢量源文件。
- 使用内置 image_gen 生成形象和图标，尺寸缩放与 ICO 封装只用于格式导出。
- 程序已更名为 Yita；本套 ICO 和 512 像素 PNG 已用于应用图标、托盘和现有 Logo 引用。
